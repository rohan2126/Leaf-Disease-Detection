# Leaf-Disease-Detection

# 🌱 Revolutionizing Plant Health Monitoring with Machine Learning for Leaf Diseases

## 📘 Project Overview

This project leverages **Convolutional Neural Networks (CNNs)** to detect and classify plant leaf diseases from images, enabling early diagnosis and promoting sustainable agriculture. It aims to assist farmers by providing a **web-based application** that gives real-time feedback and accurate disease classification using machine learning.

## 📌 Abstract

Traditional manual methods for leaf disease detection are labor-intensive, error-prone, and inaccessible to many farmers. This project proposes an **automated, scalable system** using a CNN trained on a dataset of 8,685 leaf images. With preprocessing techniques like normalization and augmentation, the model achieves **97.2% accuracy** and is deployed via a **Streamlit web interface**. The system enhances early intervention, reduces pesticide overuse, and supports **precision agriculture**.

---

## 🎯 Objectives

- Automate the identification of leaf diseases using image classification.
- Develop a deep learning model (CNN) for high-accuracy detection.
- Provide a user-friendly web interface for real-time diagnosis.
- Reduce manual labor, improve crop yield, and promote eco-friendly farming.
